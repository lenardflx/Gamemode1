# Gamemode1

A Fabric mod that restores useful legacy Minecraft command syntax and shortcuts.

* `/gamemode <0|1|2|3|s|c|a|sp> [player]`

* `/gm <mode> [player]`

* `/gms`, `/gmc`, `/gma`, `/gmsp`

* `/defaultgamemode <0|1|2|3|s|c|a|sp>`

* `/dgm <mode>`

* `/difficulty <0|1|2|3|p|e|n|h>`

* `/toggledownfall`

* `/xp <amount> [player]`

* `/xp <amount>L [player]`

* `/experience <amount>[L] [player]`

* `/locate <structure>`

* `/locatebiome <biome>`

* `/? [arguments]`

* `/replaceitem entity <targets> <slot> <item> [count]`

* `/replaceitem block <position> <slot> <item> [count]`

Works on both client and server.
With Mod Menu installed, each command group can be enabled or disabled.

> Client-side command overrides cannot provide command suggestions!
